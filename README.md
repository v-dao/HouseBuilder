# 房屋建筑软件

国标建筑施工图设计 / 施工过程模拟 / 工程量统计。

当前进度：**P0 骨架 + P1 图元与编辑命令已完成**（541 项单元测试断言全通过）。

P1 新增能力：
- 几何运算内核：偏移（含圆弧段，bulge 原样保留）、分割、修剪、延伸、打断、
  圆角、倒角、连接、求交
- 新图元：椭圆/椭圆弧、点、构造线/射线、样条曲线（Catmull-Rom 过型值点）
- 四叉树空间索引：拾取、窗选、交叉选、栅栏选
- 夹点编辑：直接拖动夹点改几何
- 26 个命令：10 个绘制命令 + 16 个编辑命令，全部带中文别名

## 环境

| 项 | 值 |
|---|---|
| 引擎 | Godot **4.7.2 stable**（标准版，非 .NET，故只用 GDScript） |
| Godot 路径 | `$GODOT` |
| 外部依赖 | **零**。DXF 读写、几何内核全部自研 |
| 图形 | Vulkan / Forward+，`msaa_2d = 4x` 提供线条抗锯齿 |

## 运行

```bash
# 首次必须先导入，生成全局类缓存，否则 class_name 全局类不可见
"$GODOT" --headless --path . --import

# 启动软件
"$GODOT" --path .

# 单元测试（无头）
"$GODOT" --headless --path . --script res://tests/run_tests.gd

# 截图验证（必须带窗口，输出到 tests/out/）
"$GODOT" --path . --quit-after 1200 res://tests/capture.tscn
```

> **注意**：脚本报错后 Godot 不会自动退出。批量任务务必带 `--quit-after` 兜底。

## 已实现的关键能力

### 图纸数据模型
- 图元是 `RefCounted` **纯数据对象**，不挂场景树。DXF 映射、撤销、序列化、
  以及后续的 3D 派生共用同一份数据
- 基于操作记录的撤销栈（新增/删除/修改的净效果），不是整文档快照
- 所有变更经 `CadDocument` 的 `add_entity` / `remove_entity` / `mark_modified`，
  保证撤销记录与渲染脏标记一致

### 几何内核
- 解析曲线抽象（线段 / 圆弧 / bulge 多段线），渲染、求交、捕捉共用
- 圆弧按**屏幕像素矢高**自适应细分（0.25px），放大不露多边形棱角
- bulge ↔ 圆弧双向转换。**注意：正 bulge 的圆弧位于弦的右侧**（已推导验证，
  反直觉，详见 `src/geom/bulge.gd` 注释）
- 线段/圆弧/圆两两求交，含切线退化与角度范围判定
- 镜像变换会反转圆弧绕向，变换后按"起点+中点+终点"三点重建而非套角度公式

### 渲染
- 按「最终颜色 + 线宽档位」分桶，每桶**一次** `draw_multiline` 提交
- 视口剔除：先用包围盒筛掉视野外图元
- 抗锯齿由视口 `msaa_2d = 4x` 提供，不用逐图元 `antialiased`（会打断批量）
- 虚线/点画线在**模型空间**切分（周期不足 2px 时退化实线），缩放时疏密不变
- 文字在屏幕空间逐条提交，旋转用 `draw_set_transform` 建立局部坐标系

### 国标符合性
- **线宽组**：b / 0.7b / 0.5b / 0.25b，b 从 1.4/1.0/0.7/0.5 中选，下限 0.1mm
- **图线用途**按 GB/T 50104 分配：墙体柱 = 粗实线 b，门窗构配件 = 中粗 0.7b，
  尺寸与符号 = 中实线 0.5b，定位轴线 / 图例填充 = 细 0.25b
- **长仿宋**：对仿宋施加 0.7 横向压缩（`FontVariation.variation_transform`）
- **字高系列**：2.5 / 3.5 / 5 / 7 / 10 / 14 / 20 mm
- **标注**：尺寸界线超出尺寸线 2.5mm、45° 中粗斜短线起止符号 2.5mm、
  尺寸数字字高 2.5mm 居上居中、平行尺寸线间距 7~10mm

### 验证
- 204 项单元测试断言（几何内核 / 国标线宽 / 序列化往返 / 撤销重做）
- 截图验证工具，出图到 `tests/out/`
- **截图前必须预热字体图集并等待 ≥12 帧**，否则会拍到白色占位纹理，
  看起来像"所有文字变成实心方块"（详见 `docs/引擎特性与坑.md`）
